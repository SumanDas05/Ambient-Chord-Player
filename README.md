# 🎧 Ambient Chord Player

A relaxing, browser-based chord player built for singers. Play soft, sustained chords, switch between instrument tones, and transpose on the fly to match your vocal range.

## Features
- 6 chord buttons (C, Am, F, G, Dm, Em) — mouse or keyboard (C A F G D E)
- 4 instrument voices (Soft Pad, Warm Piano, Pluck, Strings) — click or Spacebar to cycle
- Live transpose (+/-) to shift all chords into a comfortable key
- Volume control
- Modern glassmorphism UI, fully responsive

## Built with
- HTML, CSS, JavaScript (no frameworks)
- [Tone.js](https://tonejs.github.io/) for audio synthesis
