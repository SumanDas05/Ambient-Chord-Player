# 🎹 Ambient Chord Player

An interactive web application for playing ambient piano chords in the browser.

## Features
- Play piano chords
- Keyboard controls
- Clean and responsive UI
- Built with Tone.js

## Technologies
- HTML
- CSS
- JavaScript
- Tone.js
